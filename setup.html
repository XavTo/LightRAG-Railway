Chat & knowledge extraction

OpenAI, or an OpenAI-compatible gateway. To use Claude, configure a gateway such as LiteLLM and enter its API base URL, model alias and key.

Configured in Railway. Update LLM_BINDING_API_KEY and the model/host variables there. Clear the Railway key if you want this screen to manage the connection.

Document embeddings

Embeddings turn your documents into searchable vectors. A Claude chat connection still needs a separate compatible embedding model.

Choose the embedding model before importing documents. Changing its model or dimension later requires rebuilding the indexes.

Configured in Railway. Update EMBEDDING_BINDING_API_KEY and the embedding variables there.

Keys stay on your server and are saved encrypted on the persistent volume. They are never shown again. Saving restarts LightRAG. This does not verify provider access or include inference credits.
